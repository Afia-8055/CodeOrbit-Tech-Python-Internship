
# CodeOrbit Tech Python Internship

This repository contains three Python projects developed
as part of my one-month Python Programming Internship
at CodeOrbit Tech.

## Projects

### 1. Simple Calculator
Performs basic arithmetic operations:
addition, subtraction, multiplication, and division.
Includes input validation and division-by-zero handling.

### 2. To-Do List CLI App
A command-line task manager that allows users to
add, view, and remove tasks using a numbered menu.

### 3. Number Guessing Game
An interactive game that generates a random number
between 1 and 100 and provides hints to help the
user guess correctly. It also tracks attempts and
supports multiple rounds.

## Technologies Used
- Python 3
- Random module
- Functions
- Lists
- Loops and conditional statements
- Exception handling
